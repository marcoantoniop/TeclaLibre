# Registro de cambios

En este archivo se documentarán los cambios relevantes de TeclaLibre. Las entradas bajo «Sin publicar» describen el trabajo que todavía no se ha asociado aquí a una versión publicada.

## Sin publicar

### Funcionalidades actuales

- Motor de reasignación de teclas y combinaciones con salidas de texto o de teclas.
- Reconocimiento de modificadores, incluido AltGr, y panel para probar eventos de teclado.
- Administración de reglas y configuración, con importación y exportación.
- Opciones de inicio con Windows, funcionamiento desde la bandeja y atajo opcional para activar o detener el motor.
- Documentación inicial para usuarios y colaboradores.

### Validación

- Las funciones principales se han probado manualmente durante el desarrollo. Todavía se necesitan pruebas adicionales en diferentes entornos y distribuciones de teclado.
